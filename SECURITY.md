# Security Policy

## Supported Versions

The table below details which versions of `ha-buienradar` receive security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `ha-buienradar` seriously. If you discover a security vulnerability, please do not report it through public issue trackers or discussions.

### Reporting Process
1. Email details of the vulnerability to HiDiHo@gmail.com or open a Private Security Advisory on GitHub.
2. Include details regarding:
   - Type of issue (e.g., credential leak, unvalidated input, dependency vulnerability)
   - Step-by-step instructions or proof-of-concept to reproduce
   - Impact on Home Assistant instances
3. You will receive an acknowledgment within 48 hours.

---

## Security Best Practices for Users

- Keep Home Assistant Core updated to a currently supported release.
- Ensure your Home Assistant instance is secured behind proper TLS/SSL encryption when accessed remotely.
- Restrict access to Home Assistant API tokens and administrative accounts.
