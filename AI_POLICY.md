# AI Usage & Contribution Policy

This document defines the guidelines and policy regarding the use of Artificial Intelligence (AI) and Machine Learning (ML) code generation tools in the development and maintenance of the `ha-buienradar` project.

---

## 🎯 Policy Purpose

To maintain high code quality, security standards, and maintainability for Home Assistant users, all contributions generated or assisted by AI tools must adhere to strict principles of accuracy, verification, and human review.

---

## 📜 Principles & Guidelines

### 1. Human Responsibility
- **Accountability**: Contributors using AI tools (e.g., GitHub Copilot, Claude, ChatGPT) remain fully responsible for all submitted code, documentation, and tests.
- **Understanding**: Do not submit code generated by AI that you do not fully understand or cannot explain during code review.

### 2. Verification & Testing Requirements
- **No Hallucinated APIs**: AI models occasionally invent nonexistent Home Assistant core APIs or methods. All code must be validated against current Home Assistant Developer documentation (`developers.home-assistant.io`).
- **Local Testing**: All AI-generated code must be verified locally before opening a Pull Request.

### 3. Code Quality & Standards
- AI-generated contributions must conform to Home Assistant style standards (PEP 8, type hints, async/await paradigms).
- License compliance: Ensure AI tools do not output copyrighted code snippets violating the project's MIT License.

### 4. Transparency
- When opening a Pull Request that was significantly created or modified using AI tools, state this clearly in the PR description (e.g., *"Assisted by AI tool (Claude/Copilot)"*).

---

## 🔒 Security & Privacy
- Never input private user configuration details, API tokens, or personal identifiers into public AI model prompts.
